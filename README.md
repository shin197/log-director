# Log Director

코코포리아 세션 로그를 메시지 블록 단위로 정리하는 로컬 웹 편집기입니다. 원본과 편집본을 분리해 보관하며, 편집한 로그를 HTML·TXT·JSON·Markdown으로 내보냅니다.

## 시작하기

개발에 사용한 환경은 Windows, Node.js 24입니다. 패키지 버전은 `package-lock.json`을 기준으로 합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. 기본 주소는 `http://127.0.0.1:5173`입니다. 포트가 사용 중이면 실제 출력 주소를 확인하세요.

```sh
npm run build          # 일반 빌드 (dist/ 에 assets 분리)
npm run build:single   # 단일 HTML 빌드 (dist/index.html 1개 파일로 인라인 통합)
npm test               # Node 내장 테스트 실행
npm run format         # 기존 설정 범위 포맷
npm run format:check
```

## 현재 기능

- 코코포리아 JSON 및 자체 프로젝트 JSON 열기, 프로젝트 저장·재열기
- 메시지 선택·수정·삭제, 드래그/단축키 이동, 실행 취소·다시 하기
- 조건 검색, 선택 본문 일괄 치환, 연속 메시지 병합
- 채팅형 입력창, 캐릭터 검색, 공통 표정 선택 메뉴
- 고유 ID를 가진 캐릭터와 표정 관리, 코코포리아 클립보드 JSON 붙여넣기
- 삭제할 수 없는 시스템 캐릭터와 시스템 메시지 형식
- 채널명·타임스탬프 표시 설정, 출력 형식 설정과 미리보기
- 오류 토스트, 독립 스크롤 사이드바와 고정 툴바

로그는 페이지당 1,000개를 표시합니다. 장면 기능이나 가상 스크롤은 아직 없습니다.

## 저장과 원본

**자동 저장은 없습니다. 브라우저를 닫기 전에 프로젝트 저장을 눌러주세요.**

프로젝트 파일(`*.project.json`)에는 원본 문자열, 편집 메시지, 캐릭터와 표시 설정이 포함됩니다. 실행 취소 이력과 현재 선택·검색 상태는 저장하지 않습니다.

내보내기의 JSON은 `{title, messageCount, messages}` 형태의 완성 로그이며 프로젝트 파일과 다릅니다. 원본 파일 자체를 덮어쓰지 않습니다. 원본 보존은 문자열 기준으로, BOM을 포함한 파일 바이트의 완전 동일성까지 보장하지 않습니다. 이미지 URL은 외부에서 불러오며 이미지 파일을 프로젝트에 내장하지 않습니다.
