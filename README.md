# Log Studio

코코포리아 JSON 메시지를 블록 단위로 편집하는 로컬 웹 앱입니다.

실행: `npm install` 후 `npm run dev`. 검증: `npm test`, `npm run build`.

JSON 가져오기, 블록 추가/수정/제거, 위아래 이동, 검색, 검색 결과 선택, 선택 본문 일괄 치환, 최대 100단계 실행 취소/다시 실행을 제공합니다. 대량 로그는 100개씩 표시합니다. 이동은 검색 여부와 관계없이 전체 편집본 순서를 기준으로 합니다.

프로젝트 저장으로 원본 문자열과 편집본을 함께 보관합니다. 브라우저 종료 전 반드시 저장하세요. 자동 저장은 아직 없습니다. 원문 문자열은 수정하지 않으며 원본의 모든 필드는 그대로 포함됩니다. 내려받은 원문은 텍스트 기준 복원이며 인코딩 바이트까지 보장하는 백업은 아닙니다. 입력 원본 파일 자체는 변경하지 않습니다.

HTML/TXT 가져오기, 드래그 이동, 고급 분류, 가상 스크롤, 자동 저장은 추후 확장 대상입니다. 파서 및 편집 모델은 src/core.ts에 분리되어 있습니다.
