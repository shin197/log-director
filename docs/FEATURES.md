# 기능 및 조작 규칙

## 화면 구성

- 로그: 상단 통합 에디터 툴바(검색·치환·병합·페이지), 중앙 메시지 목록, 하단 도킹 입력창과 상태바.
- 캐릭터: 좌측 캐릭터 목록, 우측 고정 저장/삭제 바와 편집 화면.
- 설정: 프로젝트 제목, 원본 보관함, 채널/시간 표시 옵션.
- 캐릭터 사이드바 폭은 공통 CSS 변수(`--sidebar-width`)로 관리합니다.

## 선택과 편집

일반 클릭은 단일 선택, Ctrl+클릭은 추가/해제입니다. Shift+클릭은 직전 클릭의 선택·해제 상태를 구간에 적용합니다. 대상이 이미 같은 상태이면 바꾸지 않습니다. 검색 중 구간은 검색 결과 순서 기준입니다.

더블클릭으로 한 메시지만 편집합니다. 다시 더블클릭하면 저장 후 종료합니다. 취소는 해당 편집을 버립니다. 메시지 편집 중 다른 메시지로 전환할 때 미저장 내용은 자동 보존되지 않으므로 먼저 저장해야 합니다. 본문 편집 중 텍스트를 선택한 상태에서 따옴표·괄호(`"`, `'`, `(`, `[`, `{`, `` ` ``, `「`, `『`, `【`, `《`, `〈`)를 입력하면 선택 영역을 자동으로 감쌉니다.

다중 선택(2개 이상) 상태에서 상단 툴바의 `일괄 편집` 버튼 또는 `Ctrl+Shift+Enter`를 누르면 일괄 편집 모드에 들어갑니다. 커서 위치(없으면 맨 위)의 선택 메시지가 대표 편집 UI로 열리며, 캐릭터(사용자 지정 연결 해제 포함)·표정(모든 선택 메시지가 같은 캐릭터일 때)·채널·타임스탬프·주사위 판정 변경은 모든 선택 메시지에 실시간 미리보기되고 `일괄 저장` 시 하나의 실행 취소 단위로 반영됩니다. 대사 편집 영역은 수정 불가능한 `기존 대사` 블럭의 앞·뒤에 텍스트를 일괄 추가하는 특수 모드로 동작하며(방향키로 블럭을 건너뛸 수 있고, 블럭 선택 후 따옴표·괄호 입력 시 앞뒤 감싸기 가능), `Ctrl+H` 또는 `치환` 버튼으로 기존 대사 내부 문자열 치환을 실시간 적용할 수 있습니다. 일괄 편집 중 삭제는 선택 메시지를 일괄 삭제합니다.

선택한 메시지들을 드래그하거나 `Alt+↑/↓`, 또는 상단 툴바의 `오려붙이기`(`Ctrl+X`) 후 원하는 위치에 `이 곳에 붙여넣기`(`Ctrl+V`)로 일괄 이동할 수 있습니다. 서로 떨어져 있는 메시지들을 이동하면 중간의 비선택 메시지가 빠지고 선택한 메시지들이 원래 상대 순서를 유지한 하나의 연속된 덩어리로 합쳐집니다(선택된 블록 사이의 틈으로 이동하면 중간의 비선택 메시지를 앞 또는 뒤 밖으로 밀어냅니다). 오려붙이기 모드 중에는 오려진 블록이 점선 테두리와 낮은 투명도로 표시되며, 검색·페이지 이동 등 조회는 가능하지만 다른 편집은 오려붙이기를 완료하거나 취소(`Esc` 또는 `오리기 취소` 버튼)하기 전까지 잠깁니다. 잘라내기 시점에는 히스토리를 쌓지 않고 붙여넣기 완료 시 단 1회의 실행 취소 단위로 저장됩니다.

## 단축키

| 키                    | 동작                                                     |
| --------------------- | -------------------------------------------------------- |
| ↑ / ↓                 | 현재 커서에서 한 메시지 이동, 단일 선택 (필터 유지)      |
| Ctrl+↑ / ↓            | 커서 이동 및 선택 추가. 기존 선택으로 돌아가도 선택 유지 |
| Alt+↑ / ↓             | 선택 메시지들을 앞/뒤로 일괄 이동                        |
| Home / End            | 필터 해제 후 전체 로그 처음/끝                           |
| PageUp / PageDown     | 현재 목록(필터 유지)에서 10개 이동                       |
| Ctrl+Shift+Enter      | 다중 선택 중 일괄 편집 모드 진입                         |
| Ctrl+X                | 선택 메시지 오려붙이기 모드 시작                         |
| Ctrl+V                | 오려붙이기 모드 중 현재 표시 위치(또는 커서 뒤)에 붙이기 |
| Ctrl+H                | 일괄 치환 바 켜기/끄기 (일괄 편집 중에는 대사 내부 치환) |
| Delete                | 선택 메시지 삭제                                         |
| Esc                   | 오려붙이기 취소, 선택 및 메시지 편집 해제                |
| Ctrl+Z                | 되돌리기                                                 |
| Ctrl+Y / Ctrl+Shift+Z | 다시 하기                                                |
| Ctrl+A                | 검색 해제 후 전체 로그 선택                              |
| Ctrl+F                | 검색 모드 켜기/끄기                                      |

입력창에서는 텍스트 편집 동작을 우선합니다. Ctrl+F는 검색창 안에서도 토글됩니다. 열려 있는 팝업에서는 로그 전역 단축키를 처리하지 않습니다. 드롭다운은 Esc를 먼저 소비할 수 있습니다.

방향 이동 시 커서를 화면 안으로 이동시키고, 진행 방향 두 메시지의 높이 합과 300px 중 작은 값을 여백 목표로 사용합니다. 현재 구현은 렌더된 페이지의 메시지 높이만 사용하므로 페이지 경계에서는 여백이 줄어듭니다.

## 검색

`화자:제타`, `speaker:GM`, `내용:"급한 일"`, `text:공격`, `dice:성공`, `channel:메인`을 지원합니다. `-내용:잡담`은 제외 조건이며, 공백으로 연결한 조건은 AND입니다. 정규식, OR, 괄호 논리식은 지원하지 않습니다.

검색을 끄면 검색어를 지우고 전체 목록을 표시합니다. 검색어가 있는 상태에서 선택한 메시지의 우측 이동 버튼을 누르면 전체 로그의 해당 페이지로 이동해 메시지를 중앙에 배치합니다. 입력창 클릭으로도 검색을 활성화할 수 있습니다.

## 입력과 표정

채팅창의 Enter는 전송, Shift+Enter는 줄바꿈입니다. 한글 조합 중 Enter는 전송하지 않습니다. 마지막 선택 메시지 아래에 삽입하며 선택이 없으면 맨 끝에 추가합니다. 시각은 빈 문자열, 기본 채널은 메인입니다.

화자 후보는 문자가 순서대로 포함되는 검색입니다. 선택하지 않고 전송하면 정확히 일치하는 이름, 그다음 첫 후보를 사용합니다. 후보가 전혀 없으면 사용자 지정 화자가 됩니다. 시스템·사용자 지정 화자는 표정 선택이 비활성화됩니다.

메시지 편집에서는 캐릭터 이미지를 클릭해 표정을 선택합니다. 채팅창과 같은 메뉴를 사용합니다.

채널은 현재 로그의 블록들을 기준으로 자동 집계됩니다. 채널 선택 드롭다운에는 기본 채널(`(채널 없음)`, `메인`)과 메시지가 존재하는 커스텀 채널 목록이 표시되며, 맨 아래 `+ 추가` 버튼을 통해 새 채널을 직접 입력해 적용할 수 있습니다. 특정 커스텀 채널에 속한 메시지가 모두 사라지면 해당 채널은 목록에서 자동으로 제거됩니다.

## 병합

선택한 메시지들 중에서 화자·채널·유형이 같은 연속 메시지를 병합합니다. 캐릭터 ID가 달라도 표시 이름이 같으면 현재 구현에서는 병합됩니다. 첫 메시지의 ID·표정·시각·원본 위치를 유지하며 본문은 개행으로 연결합니다. 판정 결과도 개행으로 연결합니다. 시스템 메시지도 병합합니다.

## 캐릭터

일반 캐릭터는 고유 ID, 이름, 기본 이미지, 색상, 표정 목록을 가집니다. 동일 이름은 추가·이름 변경 시 거부됩니다. 캐릭터 저장으로 이름·색상·표정 변경을 함께 적용합니다. 기본 표정은 목록에서 강조하며 없으면 첫 표정을 사용합니다.

추가 팝업에서 코코포리아 `{kind:"character",data:{...}}` JSON을 붙여넣으면 바로 추가됩니다. 이름·색상·이미지·표정만 추출하고 표정 label을 이름으로 사용합니다. 메모·능력치·명령은 저장하지 않습니다.

캐릭터 삭제는 메시지를 보존하면서 연결만 해제합니다. 표정 삭제도 기존 메시지 이미지를 제거하지 않습니다. 시스템은 선택 가능한 고정 캐릭터이며 이름·색상·표정 변경과 삭제가 불가능합니다.

## 출력

내보내기는 검색·선택과 관계없이 저장된 전체 편집본을 대상으로 합니다. HTML은 렌더된 미리보기, 다른 형식은 텍스트 미리보기입니다. 편집 입력창의 미저장 초안은 먼저 저장하세요.

표시 설정은 모든 출력에 적용됩니다. JSON에서 시간 숨김은 timestamp와 createdAt을, 채널 숨김은 channel과 channelName을 제거합니다. 시스템 JSON에는 speaker 키가 없습니다. TXT는 본문, MD는 인용문, HTML은 시스템 전용 영역으로 출력합니다.
