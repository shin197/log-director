# 향후 기능 목록

다음 항목은 사용자 제안 목록입니다. 별도 요청 없이 자동으로 구현할 작업 목록은 아닙니다.

# 기능 개발 목록
- 캐릭터 탭
  - 순서 바꾸기
- 스타일 탭
  - 전체적인 html 스타일
  - 주사위 판정에 스타일 적용
  - 미리보기도 가능해야 함
  - 캐릭터마다 스타일을 저장할 수 있게 하기
- 일괄 편집중 대사 블럭이 크면 스크롤바 생기는 현상 해결
  - 메시지가 길면 ...를 붙이기?
- 캐릭터 카드 일괄적으로 통일
  - 캐릭터 탭의 캐릭터 카드를 참고
  - 검색창 내부의 칩 (pill)에는 반영하지 않음
- 장면(북마크) 기능
  - 장면은 메시지에 붙는 태그 같은 것
  - 메시지 하나에 2개 이상의 장면을 북마크 할 수 없음
  - 단축키로 장면 전환하는 기능
  - 북마크로 페이지 구분하기
- 캐릭터 편집을 통해 연결된 메세지 일괄 조작 (일부 동작)
- 불러오기 매니저
  - 여러 로그 파일을 한 번에 불러옴
  - 분할된 로그 파일들을 불러와서 이어붙임
- 배포하기
  - 단일 html 형태 ✅
  - Github Pages 형태 
- 정리 마법사
- 단축키 치트 시트 [?] 버튼
- 타임라인 화자 색상 변경

## 고급기능

- 로그에 텍스트가 아닌 다른 노드 기능?
  - 이미지?
  - 연출?
  - 흔들리는 글씨나 또는 반짝이는 글씨 등?
  - html에 서식 마크다운
- 세션의 표지나 시놉시스 넣을 수 있게 하기 (선택)
- 특수 이펙트 등으로 멋지구리한 html?
- 장면 및 줄거리를 AI로 요약?
