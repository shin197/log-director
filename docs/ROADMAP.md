# 향후 기능 목록

다음 항목은 사용자 제안 목록입니다. 별도 요청 없이 자동으로 구현할 작업 목록은 아닙니다.

## 미구현 또는 확장 필요

- 로그에 독립 이미지 삽입 및 출력
- 연속 메시지를 묶는 장면 모델 (현재 페이지와 다름)
- 주사위 결과 스타일, 캐릭터별 스타일 저장
- 검색 UI의 치환 모드 켜기/끄기
- 선택 문자열 따옴표·괄호 감싸기
- 선택/캐릭터 기준 속성 일괄 변경, 연결 해제, 여러 블록 이동
- 로컬 자동 저장·복구
- 북마크와 북마크 목록 이동
- 배포 방식 결정 및 배포
- HTML/TXT 가져오기

## 이미 구현된 관련 기반

- Ctrl+F 검색 토글, 검색 결과의 전체 로그 위치 이동
- 시스템 특수 캐릭터
- 선택 삭제와 본문 일괄 치환
- 캐릭터 이름·색상의 연결 메시지 동기화
- 단일 메시지 드래그/Alt 이동, 연속 메시지 병합

기획 시 특히 결정할 사항: 장면 경계와 병합/이동 규칙, 스타일 우선순위, 자동 저장 복구 시 기존 작업 교체 규칙, 이미지 내장 여부 및 파일 크기.
