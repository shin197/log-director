# 기능 개발 목록
- 설정 추가
- 사용자 지정 화자 / 이미지 URL 사용성 개선
  - UI상으로 사용자 지정 화자인걸 쉽게 알 수 있어야 함
  - 이탤릭으로 표기하거나 이름 옆에 도트 인디케이터
- 타임라인 스크롤 바에 장면 위치 작게 표시하기
- 타임라인에선 동시에 하나 편집하게 하기
  - 타임라인 대사, 캐릭터, 장면 중 편집 모드에 들어가면 나머지 둘이 편집 해제됨
- 배포하기
  - 단일 html 형태 ✅
  - Github Pages 형태 
- 정리 마법사
