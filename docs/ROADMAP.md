# 기능 개발 목록
- 캐릭터 탭 사이드바로 바꾸기
  - 기존에 좌측에 있는 캐릭터 바를 그대로 타임라인 편집 화면으로 가져옵니다.
  - 북마크 바와 대칭된 위치로, 상단 바의 좌측 끝의 버튼을 통해 접을 수 있습니다.
    - [<] 캐릭터 20           [추가]
  - 캐릭터 사이드 바는 기존보다 살짝 넓어집니다.
  - 캐릭터 사이드 바에 있는 캐릭터를 클릭하면, 캐릭터의 세부 내용이 아래로 펼쳐됩니다.
    - 기존의 캐릭터 탭에 있단 요소들을 이 곳에 배치합니다.
    - 아래로 펼쳐지면, 상단은 삭제/저장 버튼이 생깁니다.
  - 캐릭터 사이드 바는 스크롤이 왼쪽에 있습니다.
  - 캐릭터에게는 스타일을 여러개 적용되어있음
- 스타일 탭
  - 전체적인 html 스타일
  - 스타일은 하나의 객체임
  - 주사위 판정에 스타일 적용
  - 미리보기도 가능해야 함
  - 메시지는 여러개의 스타일 적용 가능 (체크박스 형태)
  - 캐릭터마다 스타일을 저장할 수 있게 하기
  - 메시지별로 개별 스타일 적용 가능하게 하기
  - 타깃 영역별로 직교적으로 분리되어있음
  - 겹치면 내부적으로 우선순위 적용 (우선도가 있거나 스타일 배치 순서를 따름)
- 배포하기
  - 단일 html 형태 ✅
  - Github Pages 형태 
- 정리 마법사
