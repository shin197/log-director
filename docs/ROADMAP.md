# 기능 개발 목록
- 설정 추가
- 체크박스 모양 예쁘게 하기
- 스타일 탭 다듬기
  - px 단위 조정 인터페이스 양 옆에 - + 버튼 추가하기 (google docs 스타일)
  - 정렬 왼쪽 / 가운데 / 오른쪽 아이콘 단추로 만들기
- Ctrl+G로 메시지 번호로 넘어가기
- 화자 글씨 크기 조정 가능하게 하기
- 스타일 탭의 요소들 크기 조정하기
- 배포하기
  - 단일 html 형태 ✅
  - Github Pages 형태 
- 정리 마법사
