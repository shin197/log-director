# 향후 기능 목록

다음 항목은 사용자 제안 목록입니다. 별도 요청 없이 자동으로 구현할 작업 목록은 아닙니다.

# 기능 개발 목록
- 스타일 탭
  - 전체적인 html 스타일
  - 주사위 판정에 스타일 적용
  - 미리보기도 가능해야 함
  - 캐릭터마다 스타일을 저장할 수 있게 하기
- 쿼리 개선 ✅
- 채널 체계적으로관리 ✅
- 캐릭터 스포이트
  - 메시지를 클릭해서 (Alt+클릭) 채팅창에 정보를 가져옴
- 일괄 편집중 대사 블럭이 크면 스크롤바 생기는 현상 해결
  - 메시지가 길면 ...를 붙이기?
- 캐릭터 카드 일괄적으로 통일
  - 캐릭터 탭의 캐릭터 카드를 참고
  - 검색창 내부의 칩 (pill)에는 반영하지 않음
- 필터 ON/OFF 실질적인 기능
  - ON을 하면 해당 필터를 적용함
  - OFF를 하면 해당 필터를 임시로 끄며, 내용을 비우지 않음
- 장면(북마크) 기능
  - 장면은 메시지에 붙는 태그 같은 것
  - 메시지 하나에 2개 이상의 장면을 북마크 할 수 없음
  - 단축키로 장면 전환하는 기능
  - 북마크로 페이지 구분하기
- 연속된 메시지들을 합치기 ✅
- 메시지 추가할 때 채팅창처럼 캐릭터와 표정을 고르고 적을 수 있게 하기 ✅
- 로그 네비게이션 향상 ✅
  - 키보드 네비게이션 ✅
- 메시지 표정 바꾸기 ✅
- 단축키 조작 향상 ✅
  - Ctrl Z / Ctrl Y or CtrlShiftZ 로 되돌리기/다시하기 ✅
- 메시지 검색 (Ctrl F) ✅
  - 쿼리 (화자, 내용, 탭, 등으로 검색) ✅
  - 해당 위치로 이동하기 ✅
- 전체 선택 (Ctrl A) ✅
- 선택 문자열에 따옴표, 괄호 입력시 자동 완성 ✅
- 일괄 조작
  - 선택한 것들 일괄 조작 ✅
  - 캐릭터 편집을 통해 일괄 조작
  - 속성 변경 (캐릭터 등) ✅
  - 삭제 ✅
  - 캐릭터 연결 해제 ✅
  - 이동 ✅
- 작업중인 내용 로컬 스토리지에 저장
- 시스템 메시지를 특수한 캐릭터처럼 취급하기 ✅ 
- 불러오기 매니저
  - 여러 로그 파일을 한 번에 불러옴
  - 여러 포맷의 input 지원
    - html
    - txt
    - json
    - md
  - 분할된 로그 파일들을 불러와서 이어붙임
- 배포하기 (단일 html 형태)

## 고급기능

  - 흔들리는 글씨나 또는 반짝이는 글씨 등?
- 세션의 표지나 시놉시스 넣을 수 있게 하기 (선택)
- 특수 이펙트 등으로 멋지구리한 html?
- 장면 및 줄거리를 AI로 요약?
