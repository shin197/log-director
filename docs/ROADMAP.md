# 기능 개발 목록
- 스타일 탭
  - 전체적인 html 스타일
  - 스타일 탭에서는 스타일들을 관리 가능
  - 스타일은 드래그할 수 있는 아코디언으로 관리
    - 스타일 카드을 추가/편집/복제/제거 가능
    - 각 스타일 카드에서는 샘플 메시지 1개 미리보기 가능
  - 전역 스타일
    - 최상위의 특수한 스타일
    - 메시지 외의 다른 부분까지 스타일로 편집 가능
  - 로컬 스타일
    - 이름, 필터, 스타일로 나뉨
    - 스타일에 이름을 지정 가능
    - 필터를 추가/제거 가능
    - 필터는 검색 필터에 쓰이는 필터를 그대로 사용
    - 필터에 검색되는 메시지에게 스타일 적용
    - 필터끼리는 합연산
  - 스타일은 글씨체, 메시지 패널 색, 아바타 인장 틀 등 메시지의 여러 요소를 관리
    - 하나의 메시지엔 스타일을 동시에 여러개를 지정 가능, 충돌 가능
    - 같은 속성끼리 충돌하며, 충돌할시 우선도가 강한 쪽이 적용
    - 목록 아래에 있는 스타일을 우선으로 함
    - 스타일을 지정하지 않은 속성은 기존 결과 유지
  - 내보내기 메뉴에서 미리보기도 가능해야 함
  - 설정 탭에서 스타일이 적용된 채로 작업할 수 있는 옵션 추가
  - 메시지별로 개별 스타일 적용 가능하게 하기
  - 타깃 영역별로 직교적으로 분리되어있음
  - 겹치면 내부적으로 우선순위 적용 (우선도가 있거나 스타일 배치 순서를 따름)
- 배포하기
  - 단일 html 형태 ✅
  - Github Pages 형태 
- 정리 마법사
- 기본 내보내기 스타일 원본 코코포리아랑 맞추기
