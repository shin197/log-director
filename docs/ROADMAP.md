# 기능 개발 목록
- 캐릭터 탭
  - 페이지 전환이 아니라 사이드바로 만들기?
- 스타일 탭
  - 전체적인 html 스타일
  - 스타일은 하나의 객체임
  - 주사위 판정에 스타일 적용
  - 미리보기도 가능해야 함
  - 메시지는 여러개의 스타일 적용 가능 (체크박스 형태)
  - 캐릭터마다 스타일을 저장할 수 있게 하기
  - 메시지별로 개별 스타일 적용 가능하게 하기
  - 타깃 영역별로 직교적으로 분리되어있음
  - 겹치면 내부적으로 우선순위 적용 (우선도가 있거나 스타일 배치 순서를 따름)
- 배포하기
  - 단일 html 형태 ✅
  - Github Pages 형태 
- 정리 마법사
